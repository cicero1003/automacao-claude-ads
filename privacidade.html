Política de Privacidade

Aplicativo: Automação_Claude_Ads · Contato: videira1003@gmail.com · Atualizada em: 29/10/2026

O Automação_Claude_Ads é uma ferramenta de uso interno e pessoal. Ela é usada somente pelo seu proprietário, em seu próprio computador, com as próprias contas do Google. Não há outros usuários e a ferramenta não é oferecida ao público.

Quais dados do Google o aplicativo acessa

Somente após o login e a autorização do proprietário, o aplicativo acessa dados das contas dele nos seguintes serviços: Google Ads, Google Analytics, Search Console, Tag Manager, Planilhas Google, metadados de arquivos do Drive (nome e dados do arquivo, não o conteúdo) e Perfil da Empresa. Para isso usa as permissões (escopos) solicitadas na tela de autorização do Google.

Para que usa esses dados

Apenas para o proprietário consultar relatórios, acompanhar resultados e, quando ele pedir e aprovar, criar ou alterar campanhas, tags e configurações das próprias contas. Os dados não são usados para nenhuma outra finalidade, como publicidade para terceiros ou venda de informações.

Onde e por quanto tempo os dados ficam

O acesso é guardado em arquivos protegidos no computador do proprietário. Relatórios e históricos podem ser salvos em planilhas do Google Drive dele. Os dados ficam somente enquanto o proprietário os mantiver; ele pode apagá-los a qualquer momento. O acesso expira sozinho após 6 meses sem uso e pode ser revogado como descrito abaixo.

Com quem os dados são compartilhados

Os dados não são vendidos nem compartilhados com terceiros. Os pedidos feitos pelo proprietário ao assistente de inteligência artificial são processados pelo Claude, da Anthropic, apenas para executar a tarefa solicitada. Os dados do Google obtidos por este aplicativo não são usados para treinar modelos de inteligência artificial generalizados.

Política de Dados do Usuário dos Serviços de API do Google

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como remover o acesso

Em myaccount.google.com/linkedapps, escolha o aplicativo e clique em “Remover acesso”. Também é possível revogar o login no computador do proprietário.

Direitos do titular (LGPD)

Nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018), o titular pode solicitar acesso, correção ou exclusão de seus dados pelo e-mail videira1003@gmail.com.
